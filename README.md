# Shabu · Happiness

ໜ້າຮ້ານຊາບູພາສາລາວ ສ້າງດ້ວຍ React 19, TypeScript, Vite, React Router ແລະ Redux Toolkit. ຮອງຮັບມືຖື, ແທັບເລັດ ແລະ ເດັສທັອບ.

ໂຄງການນີ້ເປັນ UX/UI ຝັ່ງບຣາວເຊີ ແລະ ໃຊ້ຂໍ້ມູນຈຳລອງທັງໝົດ. ບໍ່ມີ API, backend, ລະບົບສະມາຊິກ ຫຼື ການຊຳລະເງິນຈິງ. ຊື່ຮ້ານ, ສາຂາ, ລາຄາ, ຄະແນນ ແລະ ໂປຣໂມຊັນ ເປັນຂໍ້ມູນຕົວຢ່າງ.

## ເລີ່ມໃຊ້ງານ

ໃຊ້ Node.js 22 ແລ້ວລັນຄຳສັ່ງຈາກໂຟນເດີໂຄງການ:

```powershell
npm ci
npm run dev -- --host 127.0.0.1 --port 5174
```

ເປີດ http://localhost:5174. ໃຊ້ `npm run build` ເພື່ອກວດ TypeScript ແລະ ສ້າງໄຟລ໌ສຳລັບເຜີຍແຜ່ໃນ `dist/`. ເມື່ອໂຮສຕ້ອງຕັ້ງ SPA fallback ກັບໄປ `index.html`.

## ຂໍ້ມູນຕົວຢ່າງ

- ເມນູ 12 ລາຍການແກ້ໄຂໄດ້ທີ່ `src/data/mock.ts`.
- ໃຊ້ລະຫັດ `SHABU10` ເພື່ອຮັບສ່ວນຫຼຸດ 10% ເມື່ອຍອດອາຫານຢ່າງໜ້ອຍ ₭500,000.
- ຄ່າຈັດສົ່ງ ₭49,000 ແລະ ສົ່ງຟຣີເມື່ອຍອດອາຫານກ່ອນສ່ວນຫຼຸດຄົບ ₭999,000.
- ການຈອງ ແລະ ວັນທີຂອງຄຳສັ່ງຊື້ໃຊ້ເຂດເວລາ `Asia/Vientiane` ແລະ ຮູບແບບພາສາ `lo-LA`.

ລາຍການໂປດ ແລະ ກະຕ່າຖືກຈື່ຈຳດ້ວຍ Redux Persist. ປະຫວັດຄຳສັ່ງຊື້ ແລະ ການຈອງຕົວຢ່າງຖືກບັນທຶກໃນ localStorage ຂອງບຣາວເຊີເທົ່ານັ້ນ.
